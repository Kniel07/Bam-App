# MVP Scope — Our Little Universe

| Field | Value |
|---|---|
| Status | **DRAFT — awaiting owner approval** |
| Version | 0.1 |
| Launch | **L = the first monthsary, at the anchor minute** (exact date stored privately) |
| Time available | ~23 days from THINK start |

## 1. Scoping principle

The launch date is fixed and meaningful, so **scope flexes, the date does
not.** Anything not ready at L ships on a later monthsary, which also gives
her a reason to return each month ("the universe grows").

Security and data durability are **never** cut to save time.

## 2. Releases

### R1 — "First Monthsary" (launch at L)

**Must ship:**

| Area | Included | Explicitly excluded from R1 |
|---|---|---|
| Private access | Invite-only sign-in, 2 accounts, roles, protected routes, sign-out, recovery | Social login |
| Settings | Anchor moment, timezone, names, counter message (owner form) | Special dates, permission toggles |
| Monthsary Counter | Live Y/M/D/H/M, next monthsary + countdown, monthsary-day state | Anniversary specials |
| Our Story | Intro text, timeline, milestone photo, highlight flag, owner CRUD | Drag-and-drop reorder (use sort order field) |
| Open When Letters | Envelopes, on_demand + scheduled, opening animation, optional photo, read status, countdown, DB-enforced locking, owner CRUD | Audio messages |
| Our Memories v1 | Polaroid gallery, detail view, upload with compression, replace/delete, partner contributions | Categories, filters |
| Owner tools | In-place editing, draft/published, preview-as-partner | Consolidated admin screen |
| Ops | `noindex`, keep-alive, encrypted automated backup + one restore drill | Export UI |

**Stretch (only if all R1 must-haves pass VALIDATE by L-3):**
Reasons Why I Love You (basic: numbered list + random reveal + owner CRUD).

### R2 — second monthsary (L + 1 month)

Monthly Surprise (with archive), Our Playlist, Reasons (if not in R1) +
favorites, letter audio, memory categories/filters, special dates,
consolidated settings & permissions screen, storage usage readout.

### R3 — third monthsary and later

Easter eggs, advanced animations, extra scrapbook interactions, export.

## 3. Schedule (relative to L)

| Window | Phase | Exit gate |
|---|---|---|
| L-23 → L-21 | THINK | Owner approves THINK deliverables; independent review |
| L-21 → L-18 | DESIGN | Owner approves design system, flows, ERD, components |
| L-18 → L-7 | BUILD (incremental: auth+RLS → settings+counter → story → letters → memories → ops) | Each slice verified before the next |
| L-7 → L-5 | VALIDATE (independent) | No open critical/high defects |
| L-5 → L-2 | Fixes + **owner writes real content** | Content entered, previewed as partner |
| L-2 | Content freeze; dry run with a test scheduled letter | Test letter unlocks correctly, then deleted |
| L-1 | Restore drill verified; launch checklist signed off | — |
| **L** | Launch: share the link + her account | 🎉 |
| L+1 | Owner switches GitHub repo to private (TD-016) | Vercel still deploys |

**Critical path:** auth + RLS + letter locking. If BUILD slips past L-7,
cut in this order: Memories replace/edit → milestone photos → opening
animation polish. Never cut: auth, RLS, locking, backups.

## 4. Content the owner must prepare (not generated by AI)

- Intro story text
- Initial milestones (at least: the anchor moment)
- At least one on_demand letter and **one scheduled letter for L**
- Counter message
- Photos for memories (optional at launch)
- Display names

## 5. Out of scope (all releases)

Public registration · multi-couple support · notifications · comments/chat ·
native apps · AI-generated content · paid services.
